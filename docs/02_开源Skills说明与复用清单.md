# 「开源 skills」是什么？（按课程文档第三节）

## 一句话
**开源 skills = 别人已经做好、你可以合法复用的现成能力模块**  
（不只是聊天提示词；包括 Agent 技能包、工具库、框架、模型、数据集等。）

文档原话把这些并列在一起：
> 开源 skills、工具包、Agent 框架、模型和数据集

所以本项目里，“用开源 skills”不是扣分项，而是要求你：
1. **选得对**：它是否真能解决子任务；
2. **用得清**：来源、版本、许可证、用途写明白；
3. **改得动**：提示词/参数/接口/校验有你的适配工作；
4. **验过了**：你读过说明或代码，并验证它行为符合预期；
5. **能证明贡献**：最好用对照/消融（关掉它、换成简化版）看效果变化。

> 复用本身不扣分；说不清来源、作用、验证过程的“直接拼装”不能当有效证据。

## 课程要求你在报告里写什么
对每个复用项列出：
- 名称、版本/提交号、来源链接、许可证、具体用途
- 哪些是你编写 / 配置 / 修改 / 复用
- **至少深入分析一个**：它解决什么子任务、输入输出、依赖权限/外部服务、限制；你如何阅读并验证
- 集成时的适配：改参数、加校验、接工具、处理异常、补测试等
- 合规：不交密钥、不交隐私、尊重许可证

## 和“自己写代码”的关系
- 允许站在开源肩膀上做 Agent；
- 但 **机器学习组件必须真正支撑任务**（本项目：Ridge/Lasso 回归）；
- 单纯调通用大模型 API ≠ 满足“机器学习组件”要求。

## 将深入分析的 skill：scikit-learn 回归 Pipeline
- **子任务**：由房源特征预测月租金；比较 Linear / Ridge / Lasso。
- **输入**：数值与类别特征矩阵 X；目标 y=月租。
- **输出**：预测租金；系数/正则化路径用于解释特征影响。
- **依赖**：本地 CPU，无外部付费 API；不需特殊系统权限。
- **限制**：线性假设、对异常值敏感、类别需编码；不能保证因果解释。
- **核验方式**：固定随机种子；训练/验证/测试划分；与“仅用面积均值估价”基线对照；打印 MAE/RMSE；检查系数符号是否合理（如面积系数应为正）。

## 消融/对照（对应文档“展示复用组件实际贡献”）
1. 无模型：仅按预算+面积规则筛选。
2. 有模型：预测价参与“偏贵/合理”判断与排序。
3. Linear vs Ridge vs Lasso：误差与特征稀疏性对比。
