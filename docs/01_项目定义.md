# 项目定义（对齐课程文档）

## 项目名称
上海合租租金合理性评估与房源筛选 Agent  
（Shanghai Rent Fairness & Listing Filter Agent）

## 目标用户
在上海求学/实习的学生与应届毕业生：首次合租或整租，对“挂牌价是否合理、预算内怎么筛”缺少依据。

## 具体场景与痛点
- 现有做法：刷 App 看挂牌价，凭感觉砍价或盲目看房。
- 痛点：不知道上海同类房“公允租金”大概多少；预算、面积、行政区约束下筛选效率低；容易被异常高价误导。
- Agent 改善：用回归模型估计公允租金，接入查询/筛选/建议流程，对异常报价提示人工复核。
- 数据范围：**上海**公开挂牌整理数据（ZiRoomAgent shanghai.csv）。

## 项目范围（做 / 不做）
**做：**
1. 任务入口：用户提供预算、面积、房型、区域等约束，或粘贴一条房源特征。
2. 预测公允月租（线性回归 / Ridge / Lasso）。
3. 在房源库中按约束筛选，并结合“预测价 vs 挂牌价”给出建议。
4. 低置信/异常价人工确认；无匹配时明确失败处理。
5. 对照实验与误差、特征影响分析。

**不做：**
- 不自动下单、不爬取需登录的隐私数据。
- 不只做聊天问答；不把“调用大模型”当作核心成果。

## 成功标准（可验证）
1. **预测误差**：测试集 MAE、RMSE；Ridge/Lasso 相对普通线性回归有可比结果。
2. **任务完成率**：在固定测试任务集上，Agent 能给出“估价 + 筛选列表 + 建议”的完整输出比例 ≥ 90%。
3. **异常召回**：对“挂牌价相对预测价偏离过大”的样例，能触发人工复核提示。
4. **可复现**：按 README 安装依赖后，一条命令跑通演示与评估。

## 机器学习在系统中的位置
- 组件类型：回归预测（课程模块：租金或需求预测）。
- 输入：面积、房型、楼层、朝向、区域、整租/合租等特征。
- 输出：预测月租（元）；用于筛选排序与“偏贵/合理/偏便宜”判断。
- 贡献：没有该预测，Agent 只能做规则过滤，无法回答“值不值这个价”。

## Agent 流程（端到端）
1. 解析用户输入（预算与硬约束 / 单条房源估价）。
2. 数据工具：读取本地房源库（开源/公开数据经清洗后的 CSV）。
3. ML 推理：加载已训练的 Ridge/Lasso 模型，预测公允租金。
4. 筛选与建议：按预算与约束过滤；计算挂牌价相对预测价的偏差。
5. 失败与安全：无结果 / 特征缺失 / 极端偏差 → 说明原因并请求人工确认。
6. 返回结构化结果（步骤日志 + 最终建议）。
